# My Mercado NFC-e Extension

## Desenvolvimento
Use `manifest.dev.json` (renomeie para `manifest.json` ao carregar ou copie o conteúdo).

1. Abra `brave://extensions`
2. Ative modo desenvolvedor
3. Carregue a pasta `apps/my_mercado_extension`
4. Após alterações, clique em Recarregar

## Produção
Use `manifest.prod.json`.

Origens permitidas:
- https://www.nfce.fazenda.sp.gov.br/*
- https://mymercado.pages.dev/*

## Atualização
Após editar arquivos, clique em Recarregar em brave://extensions. Sem dependência do build do My Mercado.
